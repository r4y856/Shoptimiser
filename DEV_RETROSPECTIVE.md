#DEVELOPMENT RETROSPECTIVE#

#1. Data Collection.#

I knew that I would haave to learn the core processes of web scraping before I could tackle this project. I used a mix of video tutorials, repository boilerplate and websites created solely for practicing web scraping on.

#2. Data Transformation#

I already had a solid understanding of the concepts of pandas and duckdb, but since this was the first solo-project where I would put them into practice, I needed a syntax refresher.

Using a jupyter notebook allowed for modular and incremental development of this mainly sequential program

#3. UI#

I followed Pyside6 GUI tutorials to get the grasp of the syntax of this module. The module lends itself to an object-oriented approach, where widgets and their properties were accessed through the object hierarchy I created in the Pyside6-designer application. 

#4. Polishing up#

I only realised towards the end that a user who downloads the project may have the files in a different location to where I do. This is where I hastily read up on appdirs and made a messy attempt at resolving directory management. This messiness shows up in the final project where there may be some redundant code regarding this. I intend to make directory management an earlier consideration in future projects.
